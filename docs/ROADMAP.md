### 2026-10-30 复盘：漏掉“Pro 套餐额度翻倍”公告

原因和处理：
1. **没有官方来源**：原先只有第三方聚合站（还会晚一天以上）。已把 OpenAI 官方新闻 RSS、Anthropic 官方新闻页、Codex 定价页（网页变化，能给出前后片段）接入“chatgpt / claude / codex 动态”。
2. **价格 / 额度类消息不被当作重要**：标题含 pricing、price、usage limit、allowance、quota、credits、subscription、额度、价格、套餐、订阅、翻倍、Pro 100 等，现在直接判为“重大更新”，主题类关注会弹通知。
3. **仍然读不到的渠道**：`help.openai.com` 的 ChatGPT 发布说明页对自动化请求返回 403（网站拦截程序访问），ChatGPT 官方定价页同样 403，社交账号无法读取。Radar 不伪装浏览器绕过拦截，所以这几处暂时没有覆盖；如果重要公告只发在这些渠道，Radar 仍然会漏。
4. 试过的 Codex 更新日志页被识别成导航菜单，没有价值，已撤掉（Codex 版本已由 GitHub Releases 覆盖）。

附带修复：GitHub Releases 单次响应上限由 5MB 放宽到 25MB，否则 `openai/codex` 的发布列表（发布说明很长）会报“内容过大”。

### 这五个雷达共同需要的能力

- **新增来源类型**：JSON 接口类来源（论文、模型托管站、社区搜索）。
- **每周总结**：固定模板的周报（排序 + 比较）。与“AI 只在用户点击时运行”有冲突，只能做成可选开关，默认关闭，或做成一键生成。
- **更细的“重要更新”判定**：基于发布说明的规则分级，而不是只看版本号。
- **信息源导入**：现在只能导出，补上导入后这些雷达才方便一键恢复。

## 二、其他值得做的雷达（来自你的补充）

原文摘录，未改动判断：

**创作选题雷达**
关注某个领域的一手消息、热门新产品、开源项目和研究论文，把重要变化转化为待制作选题。可以与现有 Research2Video 项目配合：Radar 负责发现，Research2Video 负责内容生产。

**安全漏洞雷达**
根据用户关注的软件或技术栈，监测安全公告。CISA 提供机器可读的 Known Exploited Vulnerabilities（已知被利用漏洞）JSON 数据。需要新增漏洞数据解析和软件名称匹配；注意 KEV 并非所有公开漏洞的完整列表。

**职业与机会雷达**
关注目标公司的招聘页、研究资助、比赛、开源悬赏等。价值很高，但初版建议只从公开、稳定的招聘和公告来源入手，不做跨全网招聘爬虫。

**政策与规则雷达**
关注特定领域的政策公告及条款变化。例如美国 Federal Register 提供无需 API Key 的公开文档检索 API。对不同国家或行业则需要寻找相应官方来源。

### 与现有能力的对照

| 雷达 | 现有可复用 | 还缺什么 |
| --- | --- | --- |
| 创作选题 | 多来源发现、事件合并、AI 总结、问 Radar | “把变化转成选题”的输出格式；与 Research2Video 的对接方式（导出文件还是共享数据）尚未定 |
| 安全漏洞 | 网页 / RSS 采集、事件与通知 | JSON 漏洞数据解析；软件名称到漏洞的匹配规则（误报风险大） |
| 职业与机会 | 静态网页变化、列表页识别 | 稳定的招聘 / 公告来源清单；列表页遇到 JS 渲染会读不到 |
| 政策与规则 | 网页 / RSS、变化片段对比 | 公开文档检索接口的解析；各国家或行业的官方来源需要逐个找 |
